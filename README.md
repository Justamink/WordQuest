# WordQuest
WordQuest is an English learning application developed for our CS 5614 project at Virginia Tech.

# Project Description
WordQuest helps students practice English through interactive exercises. Students can choose different topics, answer questions, and track their learning progress. The application also supports teachers who manage learning content.

# Features
- English practice exercises
- Multiple-choice and free-response questions
- Topics with different difficulty levels
- Student progress tracking
- Teacher exercise management
- User account management

# Setup Instructions
For running locally:
1. Clone the GitHub repository
2. Install dependencies with `pip install -r requirements.txt`
3. Configure the database connection with a local .env file
4. Run the application using `python -m streamlit run app.py`
